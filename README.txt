AQILLI SYSTEM: Android ilova loyihasi

APK ni GitHub o'zi yig'adi (bepul). Qadamlar:
1. github.com da akkaunt oching (bepul).
2. Yangi repository yarating: tepada "+" -> New repository, nomi aqilli-apk, Public, Create repository.
3. "uploading an existing file" havolasini bosing.
4. Shu zip'ni oching va ichidagi HAMMA narsani (app papkasi, .github papkasi, build.gradle, settings.gradle, gradle.properties) brauzer oynasiga sudrab tashlang.
5. Pastda "Commit changes" tugmasini bosing.
6. Tepadagi "Actions" bo'limiga o'ting. "APK yig'ish" ishga tushadi (5-8 daqiqa). Yashil belgi chiqquncha kuting.
7. Tugagan ishni oching, pastdagi "Artifacts" bo'limidan AQILLI-SYSTEM-apk ni yuklab oling, zip'ni oching: app-debug.apk chiqadi.
8. APK ni telefonga o'tkazing va oching. Telefon "noma'lum manba" ruxsatini so'raydi, ruxsat bering. Google Play Protect ogohlantirsa, "Baribir o'rnatish" ni tanlang.
